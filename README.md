EasyConstruct Design System Prompt

You are a Senior Product Designer, Enterprise UX Architect, and Design System Engineer.

Create a complete enterprise-grade design system for a cloud-based Construction Operations Management Platform called "EasyConstruct".

The design system must serve as the foundation for all pages, dashboards, workflows, reports, forms, AI interfaces, and project management modules.

====================================
PRODUCT CONTEXT
====================================

EasyConstruct is a cloud-based construction operations management system that unifies:

• Project Management
• Workforce Management
• Human Resources
• Payroll Monitoring
• Financial Oversight
• AI Proposal Validation
• AI Issue Detection
• Workflow Automation
• Impact Awareness Analysis
• Reporting and Analytics
• Construction Documentation

The system is used by:

• Owner
• IT Designer
• Project Manager
• Human Resources
• Finance Manager
• Architect
• Engineer
• Site Personnel
• Consultant

The platform must feel:

• Professional
• Enterprise-grade
• Modern SaaS
• Data-driven
• Trustworthy
• Operationally efficient
• Construction-industry focused
• AI-powered but not futuristic

Avoid startup-style flashy UI.

Avoid gaming aesthetics.

Avoid glassmorphism-heavy interfaces.

Prioritize usability, clarity, and scalability.

====================================
DESIGN PHILOSOPHY
====================================

Design Principles:

1. Operational Clarity
   Users must immediately understand project status, workforce data, approvals, and AI insights.

2. Hierarchical Information
   Critical project information must always have visual priority.

3. Construction-Centric Experience
   Interfaces should feel suitable for engineers, architects, project managers, and executives.

4. AI as an Assistant
   AI features should support users rather than dominate the interface.

5. Enterprise Scalability
   Components should support hundreds of projects, thousands of documents, and large datasets.

6. Accessibility First
   WCAG AA compliance minimum.
